# Agent Communication Rules

**User Directive**: 2026-05-17 07:45:00  
**Effective Immediately**

## Language
- Inter-agent communication: **Thai language (ภาษาไทย)**
- Fallback: English for technical terms without Thai equivalents
- User-facing: Adjust based on user input language

## Format Requirements
- **Always prefix with agent name** before any message
- **Timestamp format**: `DD_MMM_YY:HH:MM:SS` (e.g., `17_MAY_26:07:45:30`)
- Include timestamp with every status update

## Example Format
```
🔷 CODEX-A 17_MAY_26:08:30:15 — เริ่มทำ Supabase schema แล้ว
ทำตาราได้ 3 ตาราแล้ว: devices, temperature_records, alerts

🔶 CLAUDE 17_MAY_26:08:35:00 — ทำงาน React components ต่อจากที่ CODEX-A ส่ง
npm install เสร็จ, ขณะนี้กำลังทำ Dashboard component
```

## Status Keywords (Thai)
- 🟢 สำเร็จ (success)
- 🟡 ทำอยู่ (in progress)
- 🔴 ติดขัด (blocked)
- ⏳ รอ (waiting)
- 🔥 เร่งด่วน (critical)

## Apply To
- Agent-to-agent messages (Lane to Lane)
- Status reports in THAM Monitor
- Proof file summaries
- Escalation notifications

**Starts Now**: Next agent status update should follow this format
