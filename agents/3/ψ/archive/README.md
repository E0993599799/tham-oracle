# ψ/archive

งานที่เสร็จแล้ว — completed tasks, closed sessions

## ใช้สำหรับ

- Task ที่ complete พร้อม proof
- Session retrospectives ที่ archive แล้ว
- Reference ที่ยังต้องการอยู่แต่ไม่ใช่ active

## โครงสร้าง

```
ψ/archive/
  YYYY-MM/
    task_name_PROOF.md
```

## กฎ

- ห้ามลบไฟล์ใน archive — เพียง mark ว่า superseded ถ้า outdated
- archive คือ immutable record ของสิ่งที่เกิดขึ้นจริง
