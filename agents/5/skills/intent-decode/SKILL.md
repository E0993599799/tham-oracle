# Skill: Intent Decode

## Purpose
Convert natural language into a clear task contract.

## Use When
Human gives informal commands such as ทำเลย, สั่ง Core ทำ, run ต่อ, check, close, green, fix, setup.

## Flow
1. Identify goal.
2. Identify target system/path/repo.
3. Identify allowed actions.
4. Identify risk.
5. Select execution lane.
6. Define proof needed.

## Rules
- Do not send raw natural language directly to executor.
- Preserve Human intent.
- Ask only if truly blocked.
