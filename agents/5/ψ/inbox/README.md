# ψ/inbox — สิ่งที่เข้ามา

ที่รับ tasks, messages, handoffs จาก Oracle อื่นหรือจากพี่เอก

## Format

แต่ละ item เป็นไฟล์ Markdown:
```
YYYY-MM-DD_HH-MM_<from>_<topic>.md
```

## Fields
- **From**: ใครส่งมา
- **Priority**: high / normal / low
- **Body**: เนื้อหา
- **Action needed**: สิ่งที่ต้องทำ
- **Deadline**: ถ้ามี

## Rule
ทุก item ใน inbox ต้องถูก process หรือ archive — ห้ามค้างโดยไม่มีเหตุผล
