# Skill: Core GitHub Inbox Bridge

## Purpose
Submit safe structured tasks through GitHub inbox/Core route when connector lane is required.

## Rules
- Do not bypass connector lane when task says Core/GitHub inbox.
- Create JSON task contract, not raw natural language.
- Include action, allowlist, schema, expected proof, timeout, and writeback target.
- Track ACK, processed, reject, outbox, proof, and dashboard card.
- Keep clean repo baseline safe.
