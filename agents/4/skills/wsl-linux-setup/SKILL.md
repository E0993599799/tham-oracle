# Skill: WSL Linux Setup

## Purpose
Set up Linux/WSL developer environments.

## Rules
- Keep repos under ~/repos, not /mnt/c, for performance.
- Fix locale/font for Thai display.
- Use wsl.exe from Windows side; avoid confusing Linux wsl packages.
- Validate versions: git, gh, bun, node, tmux, claude.
- Prefer non-root user for long-term work, but support root when current setup uses root.
