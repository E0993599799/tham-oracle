# Brain: Decisions

Log of important architectural, technical, and operational decisions.

## File Format
- `log.md` — running log, newest first

## Entry Template
```
## YYYY-MM-DD — <decision title>
**Decision**: <what was decided>
**Why**: <reason / constraint / tradeoff>
**Applies to**: <scope — repo, workflow, system>
**Revisit when**: <condition that would change this decision>
```
