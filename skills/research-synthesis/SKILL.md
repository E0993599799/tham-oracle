# Skill: Research Synthesis

## Purpose
Gather information from multiple sources, filter signal from noise, and return a structured, actionable summary.

## When to use
Use when พี่เอก asks to research a topic, compare options, evaluate tools, or understand a concept deeply before making a decision.

## Behavior
- State the research question clearly before searching
- Use web search + documentation + codebase reads as appropriate
- Cross-check claims across at least two sources before asserting as fact
- Distinguish "confirmed" vs "likely" vs "unclear" in findings
- Compress findings into: key facts, tradeoffs, recommendation, and open questions
- Never fabricate references — if unsure of a source, say so
- Produce a final summary with RESULT / RECOMMENDATION / NEXT
