# Skill: Dashboard UI

## Purpose
Design and wire compact live dashboards for Forge/Omega.

## Style
- Compact Tailwind UI
- Lucide icons
- Small shadow cards
- readable 15-16px fonts
- no mock data when Human says real/live
- cards read from real files/APIs

## Data Sources
agent registry, task queue, ACK, processed, reject, outbox, proof logs, lane summary, heartbeat, watchdog status.
