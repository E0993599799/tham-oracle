QUICK START (Copy & Paste)
────────────────────────────────────────────────────────────────────────────

1. Open PowerShell as Administrator
   • Press: Win + X → PowerShell (Admin)

2. Navigate to script folder
   cd C:\Path\To\Script

3. Run cleanup
   .\cleanup-and-optimize-disk.ps1

4. Wait 15-40 minutes for completion


COMMAND OPTIONS
────────────────────────────────────────────────────────────────────────────

Default (Cleanup + Optimize)
   .\cleanup-and-optimize-disk.ps1

Analysis Only (No deletion)
   .\cleanup-and-optimize-disk.ps1 -SkipCleanup

Skip Optimization (TRIM/Defrag)
   .\cleanup-and-optimize-disk.ps1 -SkipOptimization

Enable File Compression (Extra 1-2GB savings)
   .\cleanup-and-optimize-disk.ps1 -CompactFiles

Multiple Options
   .\cleanup-and-optimize-disk.ps1 -SkipOptimization -CompactFiles

  ✓ System prefetch files

  ✓ Chrome cache

Application Caches (300MB - 1.5GB)

Other (100MB - 1GB)
  ✓ Recycle Bin
  ✓ Windows cleanup files
  ✓ Downloaded program files

TOTAL EXPECTED: 1.5GB - 6.5GB FREE (typical: 2-5GB)

TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────

Script Won't Run (Execution Policy)
  Fix: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Browser Caches Not Cleared
  Cause: Browser was open during cleanup
  Fix: Close browser completely, run script again

Some Files Remain
  Cause: Files in use by applications
  Fix: Close those applications, run script again

Antivirus Slowing Down
  Fix: Temporarily disable antivirus, run script, re-enable


ADDITIONAL CLEANUP OPTIONS (If Needed)
────────────────────────────────────────────────────────────────────────────

Downloads Folder (Review first!)
  Manual: Check C:\Users\{user}\Downloads, delete old files

Old User Profiles (Backup first!)
  Settings → System → About → System protection (Advanced tab)

Disable Hibernation (4-8GB savings)
  Command: powercfg /hibernate off
  (Can be re-enabled with: powercfg /hibernate on)

Reduce Restore Points
  Settings → System → About → System protection → Configure
  (Keep at least 2-3 recent points)

Delete Windows.old (If > 30 days old)
  Backup first! Can't downgrade Windows after deletion
  Manual: Right-click C:\Windows.old → Delete


ENABLE AUTOMATIC CLEANUP (Windows 10/11)
────────────────────────────────────────────────────────────────────────────

Settings → System → Storage → Storage Sense
  ✓ Enable "Storage Sense"
  ✓ Set cleanup frequency (e.g., monthly)
  ✓ Enable all cleanup options
  → Windows will auto-cleanup from now on


MONITOR DISK SPACE REGULARLY
────────────────────────────────────────────────────────────────────────────

Check disk status:
  Command: Get-Volume | Where-Object { $_.DriveLetter -eq 'C' }

Schedule weekly cleanup:
  Option 1: Task Scheduler (Windows built-in)
  Option 2: Run script manually each week

QUICK COMMANDS
────────────────────────────────────────────────────────────────────────────

Check disk space now:
  Get-Volume | Format-Table DriveLetter, @{N='FreeGB';E={$_.SizeRemaining/1GB}},
                                          @{N='TotalGB';E={$_.Size/1GB}}

Clear specific cache manually:
  Remove-Item "$env:TEMP\*" -Recurse -Force
  Clear-RecycleBin -Force

Enable hibernation (if disabled):
  powercfg /hibernate on

Check hibernation status:
  powercfg /a
